🔧 投稿审查页面超时问题修复

⚠️ 检测到Axios请求超时错误 (timeout of 15000ms exceeded)

🚨 错误详情

错误位置: AdminDisclosurePage.tsx 第134行

错误类型: AxiosError: timeout of 15000ms exceeded

影响功能: 投稿数据加载和显示

可能原因:

  • 后端服务器响应缓慢或无响应
  • API端点配置错误
  • 网络连接问题
  • 数据量过大导致处理时间过长

✅ 已实施的修复措施

1. 延长超时时间

// src/services/api.ts const apiClient = axios.create({ baseURL: apiBaseUrl, timeout: 30000, // ✅ 从15秒延长到30秒 headers: { 'Content-Type': 'application/json', }, });

2. 优化数据加载逻辑

  • 减少单次请求的数据量（从200条降到100条）
  • 使用并行请求提高"全部"标签的加载效率
  • 添加更详细的错误信息和用户友好的提示

3. 增强错误处理

catch (e: any) { console.error('AdminDisclosurePage: load error', e); let errorMessage = '読み込みに失敗しました。'; // 更详细的错误分类 if (e.message.includes('タイムアウト')) { errorMessage = 'タイムアウトしました。ネットワーク接続を確認してください。'; } else if (e?.response?.status === 401) { errorMessage = '認証に失敗しました。再度ログインしてください。'; } else if (e?.response?.status === 500) { errorMessage = 'サーバーエラーが発生しました。しばらくしてから再度お試しください。'; } setError(errorMessage); }
