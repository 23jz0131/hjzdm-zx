# 图片资源清单

## 必需的图片文件

请将以下图片文件放置在 `public/images/` 目录下：

### 点赞相关
- `dianzan.png` - 未点赞状态图标
- `yidianzan.png` - 已点赞状态图标

### 收藏相关  
- `shoucang.png` - 未收藏状态图标
- `yishoucang.png` - 已收藏状态图标

### 评论相关
- `pinglun.png` - 评论图标

## 图片要求
- 格式：PNG
- 推荐尺寸：24x24像素或32x32像素
- 透明背景
- 清晰可辨识的图标设计

## 部署注意事项
1. 确保所有图片文件都上传到生产环境的 `/images/` 目录
2. 检查文件权限设置
3. 验证CDN或静态资源服务器配置
4. 测试各状态下图标显示是否正常

## 备用方案
如果图片加载失败，系统会自动显示对应的文本符号：
- 点赞：♡ (未点赞) / ♥ (已点赞)
- 收藏：☆ (未收藏) / ★ (已收藏)  
- 评论：💬
